# CEO Wars

Mobile business tycoon prototype built in Unity.

## Current playable loop

- Found and name a company
- Hire employees
- Generate live revenue
- Launch products for recurring revenue
- Upgrade the office and see the 3D office evolve
- CEO XP and leveling
- Premium gems
- Executive x2 revenue boost
- Instant investor cash
- Local save game
- Offline earnings (up to 8 hours)
- Portrait mobile UI

## Run

1. Open this folder with Unity 6.3 LTS.
2. Let Unity import/compile.
3. The editor setup script automatically creates and opens `Assets/CEO_Wars/Scenes/Main.unity`.
4. Press **Play**.

The game scene and UI are intentionally generated from code so the project can be rebuilt without manually wiring prefabs or inspector references.
