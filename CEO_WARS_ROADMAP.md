# CEO Wars Roadmap

## Vision
CEO Wars is a competitive mobile business tycoon: start with a tiny company, scale teams and products, expand into markets, and compete for global corporate dominance.

- [x] Company naming/onboarding
- [x] Cash economy
- [x] Employees
- [x] Products
- [x] Office upgrades
- [x] Passive income
- [x] Offline income
- [x] CEO XP and levels
- [x] Premium currency foundation
- [x] Revenue boost and instant-cash sink
- [x] Runtime-generated 3D office
- [x] Runtime-generated mobile UI
- [x] Local persistence
